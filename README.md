# Faith Vellem – Personal CV Website

This repository contains my personal CV website, built as part of the **Deployment of Static Websites** task.  
The site showcases my professional background, technical skills, and selected projects, and is deployed using **GitHub Pages**.

## Live Website
👉 **View here:** https://faithze.github.io/MyCV/

---

## Project Overview

This is a **static, single-page CV website** created using:
- **HTML5**
- **CSS3**
- **Bootstrap 5**
- **Vanilla JavaScript**

The website is fully responsive, accessible, and designed to reflect a professional yet personal online CV.

---

## Key Features

- Responsive layout using **Bootstrap 5**
- Professional profile section with image
- Clearly structured CV sections:
  - Professional Summary
  - Technical Skills
  - Selected Projects
  - Work Experience
  - Education & Languages
- **Projects displayed as interactive cards**
- **Hover animations** on project cards
- **Fade-in animations on scroll**
- **Dark Mode toggle**
  - User preference saved using `localStorage`
- **Download CV (PDF)** button
- **Back to Top** floating button
- Hosted using **GitHub Pages**

## Deployment

The site is deployed using **GitHub Pages**:

1. Repository set to **Public**
2. Main branch selected in **Settings → Pages**
3. Site accessible via GitHub Pages URL
